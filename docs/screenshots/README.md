# Screenshots

Drop PNG/JPG screenshots here with these exact filenames and the main `README.md`
will display them automatically:

| Filename | What to capture |
|----------|-----------------|
| `viewer-3d.png`   | The **3D view** tab — an orbited pallet with the corner height rulers and the green "current top" loop visible. This is the hero image. |
| `viewer-3d-labels.png` | Same view with **"Solid boxes" off and "Box labels" on**, so you can see through the stack and read each box. |
| `controls-1.png`  | Top of the **sidebar** — pallet size, optimization goal, max height, and overhang. |
| `controls-2.png`  | Rest of the **sidebar** — clearance, weight settings, stacking & stability, and the optimization effort dropdown. |
| `box-table.png`   | The editable **box table** in the main panel (the grid where you type sizes/quantities). |
| `results.png`     | The **results header** — the metric cards (boxes packed, pallets used, tallest pallet, support %). |
| `pallet-summary.png` | The **pallet summary table** from the Tables & export tab (per-pallet weight, height, cube utilization, CoG, etc.). |
| `2d-layers.png`   | The **2D layers** tab — a top-view of a pallet layer. |

When capturing the sidebar in two parts, scroll it between shots so the sections
overlap a little, so the two images read as one continuous panel.

Tips:
- Use a fairly wide browser window so the sidebar and 3D canvas both show.
- PNG keeps text crisp. Aim for ~1400px wide.
- If you rename a file, update the matching `![...](docs/screenshots/...)` line in `README.md`.
